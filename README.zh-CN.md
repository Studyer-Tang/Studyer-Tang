## 关于我

我是 **Qingjun**，北京大学学生，正在为博士阶段的研究训练做准备。我的兴趣集中在 **金融、统计学习与可复现计算** 的交叉领域。

相比单纯追求模型指标，我更关注实证结论如何成立：证据如何构造、假设如何影响结论，以及计算结果能否被追踪、复核与质疑。

> 我的研究准则：让命题足够精确，让证据可以追溯，让结论经得起挑战。

## 代表项目

### [Rigorous Research](https://github.com/Studyer-Tang/rigorous-research)

一个以证据门控为核心的研究 Skill，覆盖文献调研、数学审计、可复现计算与独立复核。它将开放式研究拆解为带有明确命题、验收条件和审查节点的分阶段流程。

`Python` · `研究方法` · `证明审计` · `可复现性`

## 研究实践

```text
文献 → 问题 → 形式化 → 计算 → 压力测试 → 表达
```

对于重要实验，我会尽量完整记录数据来源与版本、预处理决策、模型配置、随机种子、评估方案、不确定性、运行环境和已知失效情形。

目前常用工具包括 **Python、R、LaTeX、Git、Jupyter、Zotero** 与科学计算生态。工具本身不是重点；我更在意研究是否明确陈述假设、诚实披露局限，并能够经受复核。
